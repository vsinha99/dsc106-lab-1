01 / RoboticsApril 2026

RIIS — Rapid Incident Intelligence System

RIIS is a disaster response system for a ground rover entering collapsed structures. It detects survivors, streams annotated video to a command center, and coordinates triage through an agent workflow.

  • Built a YOLOv8 pose estimation backend running at about 15 frames per second on CPU, with detection latching and OpenCV skeleton overlays.
  • Used FastAPI to stream video and telemetry. An LLM generates SBAR triage assessments, and ElevenLabs supports multilingual voice contact.

2nd place overall at LA Hacks 2026.

02 / Machine learningJuly 2026

Finance LLM Router

A routing service that classifies finance tasks and sends each request to the least expensive capable model. It supports GPT-4o, Claude, and local Llama models.

  • Built a FastAPI and Docker service with Redis and Prometheus monitoring.
  • Implemented a LinUCB contextual bandit in NumPy to learn from quality feedback, plus a provider filter for financial data.

Routing lowered inference cost by about 42% compared with sending every request to GPT-4o at similar judged quality.

03 / Medical imagingApril 2026

LungIQ

A clinical decision support prototype that ingests DICOM CT scans, segments tumors, extracts radiomic features, and retrieves similar historical cases using FAISS.

  • Connected imaging and cohort data in a Python and FastAPI pipeline.
  • Presented the results as grounded, clinician-readable treatment recommendations.

Winner of the UCSD DiamondHacks 2026 Healthcare Track.
